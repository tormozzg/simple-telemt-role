= Настройка серверов для Telemt

== Подготовка на локальной машине

=== Установка Ansible

1. Установить python3, python3-venv
2. Вызвать скрипт настройки окружения `ansible_venv.sh`
3. Для активации надо вызвать `source ansible-venv/bin/activate`

== Установка Telemt

1. Создать файл с пользователями `telemt_users.yaml`
2. Создать файл `hosts.yaml`
3. Вызвать плейбук `ansible-playbook -i hosts.yaml telemt.yaml --vault-pass-file .vault_pass.txt`


* Работает только append/update. Удаления пользователей нет.
* Если хранения списка пользователей в планах нет, то можно локально держать нешифрованный файл.
* Если все таки шифруем, то создаем файл .vault_pass.txt с паролем.

=== Пример `hosts.yaml`

[source,yaml]
----
all:
  children:
    telemt:
      hosts:
        debian:
          ansible_host: telemt.cerver.com
----

=== Пример `telemt_users.yaml`

В примере secret шифрованная строка полученная командой `openssl rand -hex 16 | ansible-vault encrypt_string --vault-pass-file .vault_pass.txt`.
